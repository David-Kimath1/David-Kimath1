I started with the basics of web development and kept pulling on the thread. The way I learn hasn't really changed:

## How I Learn

I learn by building real things, not by collecting tutorials. Every project follows roughly the same loop:

```text
Learn → Experiment → Build → Break → Debug → Understand → Refactor → Document → Repeat
```

The point isn't to say I "know" a technology. It's to understand why it exists, what problem it solves, and where it fits in a larger system.

**A few things I believe:**
- Build things that are useful, or at least teach you something.
- Understand what's behind the interface.
- The first version is never the final version.
- Debugging is part of the work, not a failure of it.
- Knowledge only counts once you've applied it to something real.
